# Write modern websites using only HTML.

  

> _This site is made from vanilla HTML and the default new.css theme. [View Source](https://github.com/xz/new.css-site/blob/master/index.html)_

new.css is a classless CSS framework to write modern websites using only HTML. It's **~4.5kb.**

It's perfect for-

-   A dead-simple blog
-   Collecting your most used links
-   Making a simple "about me" site
-   Rendering markdown-generated HTML

The web was made for semantic HTML—let's start using it.
